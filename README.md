# Skeleton Showdown (Rock Paper Scissors)

A simple Rock Paper Scissors game built as part of the Foundations section of The Odin Project.

This project started as a console-based game and was later refactored into a fully interactive browser game using HTML, CSS and JavaScript.

## Live Preview

[Skeleton Showdown](https://jesvica.github.io/TOP-rock-paper-scissors/)

## Features

* Play rock, paper, scissors against a computer opponent
* Score tracking (first to 5 wins)
* Dynamic round results displayed on screen
* Game over modal with winner announcement
* Restart functionality
* Interactive UI with hover and click feedback

## What I Practiced

* DOM manipulation
* Event listeners
* Basic game logic
* Structuring JavaScript functions cleanly
* Updating UI dynamically based on state
* Separating logic from presentation
* Improving user experience with visual feedback

## Tech Used

* HTML
* CSS
* JavaScript

## Notes

This project helped me move from writing basic JavaScript logic to building something interactive in the browser. I focused on keeping the code readable and improving the user experience with small UI details.
